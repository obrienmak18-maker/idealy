- Aucun test E2E
- **Risque : bugs en production**

### 2. Pas de Déploiement
- Le code est prêt mais pas déployé
- Pas de preuve que ça marche en réel
- Pas d'utilisateurs
- **Risque : problèmes non découverts**

### 3. Coûts IA Élevés
- $15-70/user/mois sans optimisation
- Nécessite une optimisation agressive
- **Risque : modèle économique fragile**

- Multi-agents : prompts, pas de vrais agents
- **Risque : déception des utilisateurs**
