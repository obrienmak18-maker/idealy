# Spécification visuelle de référence

## Composition observée

L’image montre un workspace clair en deux grandes zones. À gauche se trouve le panneau de conversation, étroit mais suffisamment large pour afficher l’historique et la zone de saisie. À droite se trouve la zone de travail principale, beaucoup plus large, séparée par une ligne verticale très discrète.

La barre supérieure traverse toute la largeur du workspace. À l’extrême gauche, elle contient un bouton carré, une étoile, le titre de la conversation « UI/UX analysis » et un chevron. Dans la partie centrale se trouvent plusieurs boutons d’outils compacts, puis une longue barre de navigation de preview avec flèches, icône d’appareil, chemin « / », et contrôles de rafraîchissement et de menu. À droite se trouvent « Latest », un menu à trois points, un bouton de partage, un indicateur rouge « Site » et un bouton noir « Merge PR » avec menu déroulant.

Le panneau gauche contient un texte de réponse avec des puces et plusieurs paragraphes. Le contenu défile indépendamment. En bas, une zone de prompt blanche aux coins arrondis contient un bouton plus, le texte « ok », plusieurs petites icônes d’action, puis un bouton d’envoi. Sous la zone de prompt, une bande grise affiche une icône d’avertissement, « 0 messages left today. » et un lien bleu « Upgrade Plan ».

La zone droite sous la barre supérieure est une surface blanche vide de preview. Son contenu est centré : petit symbole v0 gris, titre « No Dev Script Found », puis deux lignes de texte gris expliquant que le projet n’a pas de dev script dans package.json et qu’il est encore possible de demander des changements avant d’ouvrir une PR.

## Contraintes de cette passe

Ne pas brancher les boutons. Ne pas ajouter d’agents, de mission, d’énergie, de terminal, de logique de preview ou de décisions UX. Reproduire d’abord uniquement la composition visuelle, les zones, les proportions, les couleurs, la top bar et le contenu de référence visibles dans l’image. Les fonctions seront définies par l’utilisateur dans une passe ultérieure.
