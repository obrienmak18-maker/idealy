## 🛡️ COMMENT PROTÉGER TON IDÉE

### 1. **NDA (Accord de Non-Divulgation)**
**Avant de montrer ton code** :
- Fais signer un NDA
- Protège ton code source
- Protège tes données

**Modèle simple** :
```
ACCORD DE NON-DIVULGATION
Entre [Toi] et [Investisseur]
1. L'investisseur s'engage à ne pas divulguer
   les informations confidentielles reçues.
2. Les informations incluent : code source,
   stratégie, données utilisateurs.
3. Durée : 2 ans après la fin des discussions.
Signatures : ______
```

### 2. **Dépôt de code (Preuve de création)**
**Pour prouver que c'est TON idée** :
- Dépose ton code sur GitHub (privé)
- Fais un dépôt légal (enveloppe Soleau)
- Garde des preuves de dates (commits, emails)

### 3. **Marque et nom**
- Dépose le nom "Idealy" (INPI ~200€)
- Dépose le logo
- Protège la marque

### 4. **Brevets (si applicable)**
- Le concept de gamification n'est PAS brevetable
- Le code est protégé par le droit d'auteur
