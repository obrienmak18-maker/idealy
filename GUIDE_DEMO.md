# 🎬 Guide de Démo - Présentation aux Investisseurs

## 🎯 Objectif
Démo de 15 minutes qui montre le potentiel d'Idealy.

## 📋 Script de Démo (15 min)

### 0:00-1:00 - Introduction
"Bonjour, je suis [nom], fondateur d'Idealy.
Idealy est le premier studio de développement IA gamifié.
Je vais vous montrer comment transformer une idée en application en 5 minutes."

### 1:00-3:00 - Landing Page
"Voici notre landing page.
- Design moderne
- 4 voies gamifiées
- Description simple de l'idée"

### 3:00-5:00 - Inscription
"Création de compte en 30 secondes.
- Email ou Google
- Choix de la voie (Ninja, Mage, Hunter, Pro)
- Profil personnalisé"

### 5:00-8:00 - Génération d'app
"Je vais demander : 'Crée une app de gestion de tâches avec authentification'
- L'architecte analyse
- Le développeur construit
- Le validateur vérifie
- Résultat : app complète en 2 minutes"

### 8:00-10:00 - Preview
"Voici l'application générée :
- Preview en temps réel
- Code complet
- Fichiers organisés
- Éditeur de code"

### 10:00-12:00 - Déploiement
"En un clic :
- Export GitHub
- Déploiement Vercel
- Lien public"

### 12:00-14:00 - Gamification
"Le système de gamification :
- Énergie quotidienne
- Grades et rangs
- Agents avec personnalités
- Progression"

### 14:00-15:00 - Conclusion
"Ce que nous cherchons :
- 100,000€ pour 15%
- Pour développer, marketing, opérations
- Vision : leader du dev gamifié"

## 🎯 Points clés à montrer

### OBLIGATOIRE
1. ✅ Génération d'app complète
2. ✅ Preview en temps réel
3. ✅ Code généré
4. ✅ Gamification

### SI LE TEMPS LE PERMET
5. ✅ Export GitHub
6. ✅ Déploiement Vercel
7. ✅ Éditeur de code

## ⚠️ Pièges à éviter

- ❌ Ne montre pas le code source d'Idealy
- ❌ Ne parle pas des coûts IA
- ❌ Ne montre pas les bugs
- ❌ Ne promets pas ce qui n'existe pas

## 🎯 Questions probables

### "Combien d'utilisateurs ?"
"Nous sommes en bêta avec [X] utilisateurs. Nous cherchons à accélérer."

### "Quel est votre modèle économique ?"
"Freemium : Starter gratuit, Pro 49€/mois, Business 129€/mois."

### "Quelle est votre différenciation ?"
"La gamification. Personne ne gamifie le développement d'applications."

### "Pourquoi vous ?"
"J'ai créé ce produit seul. Je suis passionné et déterminé."

## 📊 Métriques à avoir

- [ ] Nombre d'utilisateurs
- [ ] Nombre de missions générées
- [ ] Taux de rétention
- [ ] Revenus (si applicable)
- [ ] Témoignages

- La génération d'app (2 min)
- La gamification (unique)

- Les bugs

- Le code source
