# ACCORD DE NON-DIVULGATION (NDA)

## Entre les parties

**Le Divulgateur** : [Ton nom], fondateur d'Idealy

**Le Récipiendaire** : [Nom de l'investisseur]

## 1. Objet
Le Récipiendaire s'engage à ne pas divulguer les informations confidentielles reçues dans le cadre des discussions sur Idealy.

## 2. Informations confidentielles
- Code source
- Stratégie commerciale
- Données utilisateurs
- Modèle économique
- Plans futurs
- Toute information non publique

## 3. Obligations
Le Récipiendaire s'engage à :
- Ne pas divulguer les informations
- Ne pas utiliser les informations pour son propre compte
- Ne pas copier le code
- Ne pas créer un produit concurrent

## 4. Durée
Cet accord reste en vigueur pendant 2 ans après la fin des discussions.

## 5. Exceptions
Ne sont pas confidentielles :
- Les informations déjà publiques
- Les informations reçues d'une tierce partie
- Les informations développées indépendamment

## 6. Sanctions
Toute violation peut entraîner :
- Des dommages et intérêts
- Des poursuites judiciaires

## 7. Loi applicable
Droit français. Tribunal de Paris.
